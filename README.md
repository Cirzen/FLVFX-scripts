# FLVFX Scripts

FL Studio VFX Patcher scripts for MIDI control and modulation.

## Scripts

### Multi-Phasic Oscillator

Creates up to eight sine-wave controller outputs. The outputs use different
phase positions. You can sync the cycle to the song position or run it
continuously. Use the controls to change the cycle length, speed, spread,
tension, direction, scale, and offset.

### Swing by Delay

Delays every other note to create a swing feel. Select an 8th-note, 16th-note,
32nd-note, automatic, or custom timing grid. Set the swing amount and choose
whether delayed notes keep their original length.

## Use

1. Open FL Studio Patcher.
2. Add a VFX Script.
3. Open the Script tab.
4. Paste the contents of a script into the tab.
5. Reload or run the script.
